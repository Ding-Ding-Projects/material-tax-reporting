# PDF features

This category documents local PDF preparation for annual personal tax returns.

## Articles

- [CRA mail-in PDF package](cra-mail-package.md) — supported 2025 Ontario forms, local assembly, unsupported situations, attachments, privacy boundaries, and official sources.
- [Mandatory manual review](manual-review.md) — the fail-closed state machine that controls local export and printing.

## Scope

The current repository foundation does not provide a user interface, a concrete PDF adapter, verified physical PDF field profiles, a built application, or a released artifact. The package defines the bounded preparation contracts for those later components.

No feature in this category files a return. NETFILE, EFILE, electronic submission, direct CRA transmission, simulated filing, and automatic filing are prohibited.
