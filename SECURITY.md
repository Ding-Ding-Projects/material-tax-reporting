# Security Policy

## Current support status

This repository is in a foundation-only stage and has no released or supported application versions. No executable, installer, hosted site, tax engine, or filing service is currently provided.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Ding-Ding-Projects/material-tax-reporting/security/advisories/new) for security-sensitive reports. Do not include vulnerability details, credentials, tax records, government identifiers, or other personal information in a public issue.

If private vulnerability reporting is unavailable, open a public issue that asks only for a private contact route. Do not describe the vulnerability publicly.

Please include the affected commit or future version, the observed impact, and minimal reproduction steps using synthetic data. Maintainers will acknowledge the report when available and will publish remediation information only after disclosure is safe.

## Data handling

Never submit real taxpayer data to this repository, its issues, pull requests, discussions, logs, or example files. Future application code must keep local tax data private by default and must document any boundary that could move data outside the user's computer.
